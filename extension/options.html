IUH Fast Login

Tự động đăng nhập sv.iuh.edu.vn mà không cần nhập captcha.

Cách hoạt động

  1. Extension chặn request ảnh captcha /WebCommon/GetCaptcha ngay ở tầng mạng (declarativeNetRequest).
  2. Server chỉ bật kiểm tra captcha khi ảnh đó đã được tải trong phiên — nên khi bị chặn, server bỏ qua captcha.
  3. Content script điền MSSV/mật khẩu và bấm nút đăng nhập; JS của trang tự mã hoá mật khẩu.
Lưu ý: server giới hạn tần suất đăng nhập (~10 giây/lần). Nếu đăng nhập liên tục sẽ bị từ chối; extension tự chờ rồi thử lại.

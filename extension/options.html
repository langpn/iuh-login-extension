IUH Fast Login

Tự động đăng nhập Cổng Sinh Viên (sv.iuh.edu.vn), LMS Moodle (lms.iuh.edu.vn) và hỗ trợ Cổng ĐKHP (dkhp.iuh.edu.vn).

Cách hoạt động

  1. Cổng SV (sv.iuh.edu.vn): Extension chặn request ảnh captcha /WebCommon/GetCaptcha ở tầng mạng (declarativeNetRequest), server tự động bỏ qua captcha.
  2. Cổng LMS Moodle (lms.iuh.edu.vn): Tự động điền tài khoản và đăng nhập trực tiếp.
  3. Cổng ĐKHP (dkhp.iuh.edu.vn): Tự động điền form, tối ưu giao diện Dark/Light mode và định kỳ gửi keepalive giữ phiên cookie (.ASPXFORMSAUTH) không bị văng.
Lưu ý: server giới hạn tần suất đăng nhập (~10 giây/lần). Nếu đăng nhập liên tục sẽ bị từ chối; extension tự chờ rồi thử lại.
